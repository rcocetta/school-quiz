What is it?

A quiz is a short text file with questions and answers. school-quiz turns it into a friendly web page with big buttons, a kind word when an answer is wrong, a score at the end, and a fresh mix of questions every time. Grown-ups write the questions. Children tap the answers.

How it works

Three steps. You do not need to know how to program. Writing questions happens in your browser. Publishing needs one small tool, and you can ask a friend or the project for help with that.

  1. Fork it

    “Fork” just means making your own copy of school-quiz on GitHub. It is one click and it is free.

  2. Write your questions

    Open a simple text file in your browser. Type a question, add the answers, mark the right one. GitHub checks it for slips.

  3. Build and publish

    One command builds your site into a folder called docs, and GitHub Pages shows it to the world. Then send the address to your class or your family.
